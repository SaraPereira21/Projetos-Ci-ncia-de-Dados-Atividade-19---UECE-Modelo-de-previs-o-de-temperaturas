# Previsão de Temperaturas — Projeto de Ciência de Dados

Este projeto foi desenvolvido como atividade da minha formação em Ciência de Dados pela UECE.

A proposta foi estudar uma série de temperaturas e construir um modelo simples de previsão, passando pelas etapas de preparação dos dados, visualização e treinamento do modelo.

## O que foi utilizado

- Python;
- NumPy e Pandas para manipulação dos dados;
- Matplotlib para visualização;
- Scikit-learn para preparação e normalização;
- TensorFlow/Keras;
- rede neural LSTM para trabalhar com a sequência temporal.

Os dados utilizados na atividade são **dados fictícios de temperatura**, gerados para fins de estudo.

## Por que mantenho este projeto aqui

É um projeto acadêmico e não representa um modelo de previsão em produção. Mantenho no portfólio porque faz parte da minha evolução em Ciência de Dados e foi um dos exercícios em que comecei a trabalhar, na prática, com preparação de dados e modelos para séries temporais.

Ainda estou desenvolvendo meu conhecimento nessa área e quero evoluir principalmente na avaliação dos modelos, comparação de resultados e entendimento das limitações de cada abordagem.
